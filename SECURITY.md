# Security policy

doorkeep is security software; reports are taken seriously and handled fast.

## Reporting a vulnerability

Use GitHub private vulnerability reporting on this repository. Include the
version or commit, a reproducible proof of concept, and the impact. Reports
without a proof of concept may be deprioritised.

Do not open public issues for security problems.

## Scope

In scope: the Go server, the browser snippet, the dashboard, the official
integrations and the Docker images in this repository.

Out of scope: third-party sites that deploy doorkeep, denial of service by
volume, and bypasses that require controlling the visitor's real browser with
human-like input (see the threat model in docs/design/v1.md section 9).

## Timeline

Acknowledgement within 3 days, assessment within 14 days, fix and advisory as
soon as a patch is ready. Credit is given unless you prefer otherwise.
